# SpringBoot CRUD API with JWT Authentication
This project is a RESTful API built with Spring Boot that provides CRUD (Create, Read, Update, Delete) operations on resources. The API is secured using JSON Web Tokens (JWT) for user authentication. Once authenticated, users can perform CRUD operations to alter the pizza website.

# Features
JWT Authentication: Secure your API endpoints with JWT-based authentication.

CRUD Operations: Perform Create, Read, Update, and Delete operations on your resources.

Role-Based Access Control: Manage user roles to restrict access to certain endpoints.

Spring Data JPA: Simplifies database interactions with an abstraction layer over JPA.

MySQL/PostgreSQL Support: Out-of-the-box support for popular relational databases.

Custom Exception Handling: Graceful error handling with custom exception responses.

# Tech Stack
Spring Boot: A Java-based framework used to create stand-alone, production-grade Spring-based Applications.

Spring Security: A powerful and highly customizable authentication and access-control framework.

JWT (JSON Web Tokens): A compact, URL-safe means of representing claims to be transferred between two parties.

Spring Data JPA: Provides a consistent data access API for relational databases.

Hibernate: An ORM framework for mapping an object-oriented domain model to a relational database.

Maven: A build automation tool used for managing project dependencies and lifecycle.
